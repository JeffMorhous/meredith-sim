# Working on meredith simulator

This game is a gift for Meredith. Keep Mere and Bear recognizable, errands low-pressure, and movement comfortable on a phone as well as a keyboard.

## Repository and releases

- Work from the Git root containing `dist/` and `build_gift.py`. In the original workspace this is the nested `game/` checkout. Run Git commands there so the changes land in `JeffMorhous/meredith-sim`.
- **Vercel is the only deployment target.** The GitHub integration publishes `main` to [the production game](https://meredith-sim.vercel.app/). The ChatGPT Sites workflow is retired. Skip its tools for source sync, packaging, and publication. The legacy `.openai/hosting.json` has no role in a Vercel release.
- `dist/` is both the editable source and the directory Vercel serves. The [README](README.md) has the local server command and Vercel settings. The optional single-file gift is generated by `build_gift.py` and lives outside this repository.

## Where to make a change

| File | Responsibility |
| --- | --- |
| `dist/index.html`, `dist/style.css`, `dist/icons.js` | Game shell, controls, responsive layout, and icons |
| `dist/game.js` | Input, HUD, dialogs, journal, shop, landmark actions, and travel destinations |
| `dist/world.js` | Canvas rendering, meadow geometry, pathfinding, camera, map crossings, and Bear’s follow animation |
| `dist/life.js` | Progression, economy, daily errands, furniture placement, save validation, and persistence |
| `dist/orchard.js`, `dist/orchard.css` | Orchard map, apple and birdsong minigames, and missing-bell adventure |
| `dist/cottage.js`, `dist/cottage.css` | Cottage map, furnishings, placement slots, collision footprints, and decorating UI |
| `dist/music.js` | Web Audio soundtrack and interaction cues, enabled by the sound control |
| `dist/assets/` | Map art, local font and license, and Mere and Bear’s sprite atlases and portraits under `pets/` |

### Preserve existing saves

Use `CozyLife` methods for state changes. `CozyLife.getState()` returns a snapshot that’s handy in the local browser console. The save key is `mere-and-bear.life.v1`. Add defaults or migrations in `life.js` when changing the schema. Keep scene, chore, item, and slot IDs stable or migrate them before `load()` filters unknown values.

`points` is the spendable balance. `totalPoints` counts lifetime earnings and unlocks Meredith’s letter. Rest resets the daily `completed` list. Furniture placement maps a slot ID to an owned item ID, and `bellStage` records progress across days. Keep scene and position together when saving a move. Use a local browser profile for save experiments.

### Connect a landmark or map

Define positions in the world’s 1000 × 409 coordinate system. The landmark’s `x` and `y` mark where Mere’s feet can reach it, and its `area` is the clickable rectangle over the art. For a walk-through exit, `exit.left` and `exit.right` span the opening, `y` sets the threshold, and `exit.direction` is currently `"up"` or `"down"`.

Route the landmark ID through `visit()` in `game.js`. Choose a walkable arrival spot clear of the return threshold. For a new scene, also register it in `CozyWorld.start()`, add it to the scene allowlist in `life.js`, and update the destinations and journal routing in `game.js`. For changes to Bear’s movement, check with Bear fed so he follows Mere through turns and around obstacles.

### Refresh game assets and verify

The deferred scripts in `index.html` share browser globals. Orchard and cottage load before `life.js`, which reads their catalogs at startup. `game.js` loads last and starts the world. When editing a linked script or stylesheet, update its `?v=` in `index.html` to the first ten hex characters of its SHA-256. For example, `shasum -a 256 dist/world.js | cut -c1-10` prints the version for `world.js`.

There is no checked-in test runner. For JavaScript changes, run the syntax check below, then exercise the affected feature in the local game. Choose the checks that match the change.

```sh
for file in dist/*.js; do node --check "$file" || exit 1; done
```

- **Movement or input** — Walk into and out of the cottage and orchard. Hold the movement key through arrival to check for bounce-back. Try the on-screen pad and tap-to-walk at phone width.
- **Rewards or saves** — Complete an errand, buy an item, and refresh. Check the balance, ownership, location, and whether the errand can pay out twice that day. Rest and check the next day’s journal.
- **Decorating** — Place an owned furnishing, leave the cottage, return, and reload. Check its position and walk around anything with a collision footprint.
- **Scripts or art used by the offline copy** — Run the gift packager and open its output with the browser offline. It expects local deferred classic scripts and rewrites asset references to data URLs. Follow an existing asset reference when introducing new art.
